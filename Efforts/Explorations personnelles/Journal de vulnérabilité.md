# Journal de vulnérabilité

Une entrée courte quand je vis (ou évite) un moment de vulnérabilité, dans le couple ou dans un projet. Pas besoin de bien écrire : juste garder une trace.

## Modèle d'entrée

```
### AAAA-MM-JJ
- Situation :
- Ce que j'ai fait (Yang : trancher, expliquer, solutionner, rassurer, faire de l'humour…) :
- Ce que j'aurais pu faire (Yin : ne pas savoir, demander, dire ce que je ressens, recevoir…) :
- Ce que j'ai ressenti dans le corps :
- Peur derrière (humiliation, imposteur, perdre ma place…) :
- Ce qui s'est passé ensuite / sa réaction :
```
