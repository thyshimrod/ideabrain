> **Quel est le but de l’Ennéagramme ?  
> Désidentification ? Intégration ? Transcendance ?**

Je te propose une lecture en **4 niveaux** :

1. Intention fondamentale
    
2. Statut du type
    
3. Rôle de l’intégration (flèches, ailes…)
    
4. Vision de la “guérison / illumination”

# 🧭 Carte comparative des auteurs de l’Ennéagramme

## 1. Oscar Ichazo (origine spirituelle)

### 🎯 But de l’Ennéagramme

👉 **Libération de l’ego et réalisation de l’Essence**

Ichazo conçoit l’Ennéagramme comme :

- une **carte des fixations de l’ego**
    
- un chemin vers l’**État d’Être essentiel**
    

### 🧠 Statut du type

- Le type = **fixation mentale**
    
- Une distorsion de la réalité
    
- Un obstacle à la liberté intérieure
    

> Le type n’est jamais une identité légitime.

### 🔄 Intégration (flèches)

- Secondaire
    
- Utile pour comprendre les mouvements de l’ego
    
- **Pas un objectif**
    

### 🌱 Guérison / illumination

👉 **Sortir complètement de l’identification à toute fixation**

📌 Chez Ichazo, l’Ennéagramme est un **outil de déconditionnement**, pas de développement de la personnalité.

---

## 2. Claudio Naranjo (psychologie + spiritualité)

### 🎯 But de l’Ennéagramme

👉 **Voir la névrose pour s’en libérer**

Naranjo parle explicitement de :

- **structures névrotiques**
    
- mécanismes de défense précoces
    
- automatisme émotionnel
    

### 🧠 Statut du type

- Le type = **stratégie de survie**
    
- Forgée dans l’enfance
    
- Maintenue par la peur et l’attachement
    

> Le type est une pathologie “normalisée”.

### 🔄 Intégration

- Vue comme un **rééquilibrage**
    
- Pas une finalité
    
- Peut devenir un piège si elle est idéalisée
    

### 🌱 Guérison

👉 **Dé-identification progressive par conscience + présence**

📌 Pour Naranjo, on ne “devient pas un bon type”,  
on **cesse de fonctionner depuis la névrose**.

---

## 3. Don Richard Riso & Russ Hudson (pont grand public)

### 🎯 But de l’Ennéagramme

👉 **Augmenter le niveau de conscience**

Ils parlent moins de “libération de l’ego” que de :

- choix conscient
    
- présence
    
- responsabilité intérieure
    

### 🧠 Statut du type

- Le type = **structure de personnalité**
    
- Ni bon ni mauvais
    
- Mais limitée
    

> Le problème n’est pas le type, mais l’identification rigide.

### 🔄 Intégration

- Centrale dans leur modèle
    
- Les flèches = récupération de qualités perdues
    
- Les niveaux de santé = chemin d’évolution
    

⚠️ Risque :

- être lu comme “devenir un type amélioré”
    

### 🌱 Guérison

👉 **Passer d’une personnalité défensive à une présence incarnée**

📌 À haut niveau de santé :

- le type devient transparent
    
- il n’est plus le centre de l’identité
    

---

## 4. A.H. Almaas (Diamond Approach – référence clé pour ta question)

### 🎯 But de l’Ennéagramme

👉 **Réalisation de l’Essence et sortie de la transe de la personnalité**

C’est l’auteur le plus clair sur ton point.

### 🧠 Statut du type

- Le type = **substitut à une qualité essentielle perdue**
    
- Exemple :
    
    - le 7 remplace la joie essentielle par l’excitation
        
    - le 5 remplace la présence par le retrait
        

> La personnalité est une **compensation**, pas une identité.

### 🔄 Intégration

- Flèches, ailes, centres = **phénomènes secondaires**
    
- Peuvent apparaître naturellement
    
- **Mais ne sont pas le but**
    

### 🌱 Guérison

👉 **La désidentification est une conséquence, pas une pratique**

Quand l’Essence est retrouvée :

- le type s’effondre de lui-même
    
- sans effort
    
- sans combat
    

📌 Phrase clé (esprit Almaas) :

> On ne quitte pas le type.  
> On cesse d’en avoir besoin.

---

## 5. Sandra Maitri (Essence & Ennéagramme)

### 🎯 But

👉 **Retrouver la qualité essentielle derrière chaque type**

### 🧠 Statut du type

- Le type est une **déviation énergétique**
    
- Chaque type masque une Essence spécifique
    

Ex :

- 7 → Joie essentielle
    
- 5 → Connaissance essentielle
    
- 8 → Force essentielle
    

### 🔄 Intégration

- Vue comme une **réharmonisation**
    
- Pas comme un objectif identitaire
    

### 🌱 Guérison

👉 **Habiter l’Essence rend le type obsolète**

---

## 6. Beatrice Chestnut (approche contemporaine)

### 🎯 But

👉 **Conscience + transformation relationnelle**

Elle reste plus psychologique que spirituelle.

### 🧠 Statut du type

- Pattern adaptatif
    
- Influencé par le sous-type
    

### 🔄 Intégration

- Utile
    
- Pratique
    
- Mais pas ultime
    

### 🌱 Guérison

👉 **Diminution de la compulsion et élargissement du choix**

📌 Elle n’insiste pas autant sur la “dissolution de l’ego”,  
mais ne contredit pas les auteurs plus spirituels.

# 🧩 Synthèse transversale (réponse directe à ta question)

### ✔️ Oui, le but est bien la désidentification

Mais :

- pas par rejet du type
    
- pas par effort volontaire
    
- pas par accumulation d’autres types
    

### ❌ Non, l’intégration (ex : 7 → 5) n’est pas le but final

👉 C’est :

- une **étape**
    
- un **signe de maturation**
    
- parfois un **effet secondaire**
    

### ❌ Non, il n’est pas nécessaire de “faire le tour des types”

👉 Ce qui est intégré, ce sont :

- des **qualités universelles**
    
- pas des identités typologiques
    

### ✅ La guérison réelle ressemble à ceci :

- le type est toujours reconnaissable
    
- mais il n’est plus compulsif
    
- il n’est plus défensif
    
- il n’est plus “moi”
